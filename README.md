# 瓦片编辑器 · Tile Editor

一个纯前端、零依赖、开箱即用的网页版瓦片地图编辑器。基于 [Kenney](https://kenney.nl/) 的 Tiny 系列像素素材包，用于绘制俯视角（top-down）瓦片地图，并导出可被游戏直接消费的 JSON。

设计核心：覆盖级别（lvl）与障碍（solid）严格取自《瓦片素材表.xlsx》，只读。编辑器只是数据的可视化与绘图界面，瓦片的层级、可否穿过等"规则属性"由素材表统一决定，避免手绘时属性错乱。

## 功能特性

- 五套内置素材：`battle` / `dungeon` / `farm` / `ski` / `town`，共数百张 Kenney Tiny 瓦片
- 智能调色板：按「来源 / 覆盖级别 / 障碍」分段筛选，支持关键字搜索（如 `耕地`、`farm-0`）
- 三种工具：画笔（左键放置、可拖动连续刷）、橡皮（移除最上层）、取色（吸取地图上某格最上层瓦片）
- 多级缩放：1× / 2× / 3× / 4×
- 可视化开关：网格、覆盖级别着色、障碍蒙层、与 JSON 差异高亮
- 画布管理：调整尺寸（保留左上角内容）、新建地图、清空、撤销（Ctrl/⌘+Z）
- 地图存档：命名保存到浏览器本地（localStorage），随时载入继续创作；编辑自动暂存，刷新不丢
- 导入 / 导出 JSON：与游戏端格式互通
- 渲染规则：每格内瓦片按 `lvl` 升序由下往上绘制，高层（树顶/屋顶）自然遮挡低层（地面），不会出现"走到房顶上"

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript（无框架、无打包器、无第三方运行时）
- Canvas 2D 渲染
- 瓦片图来自 Kenney 素材包（PNG），属性数据来自 `editor-data.js`

## 快速开始

方式一（最简单）：用浏览器直接打开 `editor.html` 即可，无需安装或构建。

方式二（推荐，避免个别浏览器对 `file://` 的限制）：在项目根目录起一个本地静态服务器，再访问 `editor.html`：

```bash
# Python 3
python -m http.server 8000
# 浏览器打开 http://localhost:8000/editor.html

# 或 Node
npx serve .
```

## 界面与操作

界面分为三栏：

- 左侧调色板：筛选与搜索瓦片，点选要绘制的瓦片
- 中间画布：左键单击/拖动放置；右键单击 = 橡皮；悬停查看格子详情
- 右侧检查器：选中瓦片信息、当前格子瓦片栈、地图统计、地图存档、图例与操作说明

常用操作：

- 画笔 / 橡皮 / 取色：切换绘制模式
- 缩放 1×–4×：调整画布显示比例
- 网格 / 覆盖级别 / 障碍 / 与JSON差异：可视化开关
- 调整尺寸 / 新建地图：修改画布大小
- 加载示例地图：载入内置示例（农场 / 地牢）
- 撤销 / 清空 / 导出 JSON / 导入 JSON：编辑与存档

## 覆盖级别与障碍（重要）

瓦片的 `lvl`（覆盖级别）与 `solid`（是否可穿过）由《瓦片素材表.xlsx》唯一决定，编辑器内只读。约定如下：

| 级别 | 含义 | 示例 |
| --- | --- | --- |
| 0 | 装备 / 背包 / UI（不进入地图） | — |
| 1 | 背景地面 | 草地、雪地、水面 |
| 2 | 作物 / 草 / 旗帜 / 箭头 | 耕地、灌木 |
| 3 | 实体单位 | 玩家、动物、建筑、树、载具 |
| 4 | 房顶 / 树顶（可穿过，优先显示） | 屋顶、树冠 |

- 障碍蒙层沿用 Tiny-realm 游戏内样式：深墨绿蒙层 + 细白描边。
- 与 JSON 差异：高亮"素材表障碍判定 ≠ 原地图 JSON 中 `blocked`"的格子，方便核对。
- 如需增删瓦片或修改其 `lvl` / `solid`，请以《瓦片素材表.xlsx》为准，并重新导出 `editor-data.js`（仓库当前未纳入导出脚本）。

## 导出 / 导入格式

导出为 JSON，顶层字段：

```json
{
  "generator": "Tile Editor export (lvl/solid from 瓦片素材表.xlsx)",
  "width": 30,
  "height": 17,
  "tileSize": 16,
  "packDirs": { },
  "legend": {
    "town:tile_0000": { "file": "kenney_tiny-town/Tiles/tile_0000.png", "level": 1, "solid": false }
  }
}
```

- `legend` 记录每个 `包:瓦片ID` 对应的图片路径、覆盖级别与障碍。
- 地图数据按格存储「瓦片栈」，渲染时按 `level` 升序绘制。

## 目录结构

```
tile-editor/
├── editor.html            # 编辑器主页面（HTML + CSS + JS 内联）
├── editor-data.js         # 瓦片数据(TILE_DATA)与示例地图源(MAP_SOURCE)，由素材表导出
├── 瓦片素材表.xlsx         # 瓦片元数据源（lvl/solid 的权威来源）
├── 农场示例地图.json       # 导出格式示例（农场）
├── 地牢示例地图.json       # 导出格式示例（地牢）
└── kenney_tiny-*          # 五套 Kenney Tiny 素材包（含 License.txt）
    ├── kenney_tiny-battle
    ├── kenney_tiny-dungeon
    ├── kenney_tiny-farm
    ├── kenney_tiny-ski
    └── kenney_tiny-town
```
